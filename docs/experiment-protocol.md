## 1. 数据生成

- **正常数据**：二维两个高斯簇，形成密度异质性。
  - 密集簇：均值 $(-2,0)$，协方差 $0.25I$。
  - 稀疏簇：均值 $(2,0)$，协方差 $I$。
- **异常（三类，各占 1/3，测试异常比例 20%）**：
  - 远端 distal：$x\in[5,7]$、$y\in[-1,1]$ 均匀采样（稀疏簇右侧 3–5 个标准差外，易检基线）。
  - 边界 boundary：$x\in[4,5]$、$y\in[-1,1]$ 均匀采样（稀疏簇尾部 2–3 个标准差，难检，用于 H2/H3）。
  - 空区紧凑簇 compact：$\mathcal N((0,0), 0.15^2 I)$ 的紧凑小簇（局部密度高、全局密度低，用于拉开 KDE vs LOF 的视角分歧）。
- **1D 带宽示意**：一维双峰（两个高斯 $\mathcal N(\pm 2, 0.5^2)$ 各 200 点），仅作原理图，不混入二维检测性能。

## 2. 划分协议

| 集合 | 内容 | 用途 |
|---|---|---|
| train | 仅正常（每簇 250） | 拟合 KDE / LOF |
| validation | 仅正常（每簇 150） | 校准阈值 |
| test | 正常（每簇 150）+ 远端异常（20%） | 最终评估，流程锁定后只用一次 |

- 随机种子：`train=1701`、`validation=1702`、`test=1703`；异常采样用 `test+1000`。
- 拓展多种子列表（预先公布，看结果前锁定）：`[42, 43, 44, 45, 46]`，每组用 `(s, s+100, s+200)` 分别作 train/val/test 种子。
- 标准化等数据变换**只在训练数据拟合**；本项目原始二维数据不强制标准化，如需标准化须写明并只用 train 统计量。

## 3. 数据字典

| 名称 | 形状 | 标签编码 | 用途 |
|---|---|---|---|
| `X_train` | (500, 2) | 无标签，全正常 | 拟合 |
| `X_val` | (300, 2) | 全正常 | 校准阈值 |
| `X_test` | (300, 2) + 异常 | `y_test` 0=正常 1=异常 | 最终评估 |
| `c_test` | 同 `X_test` | 0=密集簇 1=稀疏簇 -1=异常 | 分簇误报率 |

## 4. 参数网格（先定，看结果前锁定）

- KDE 高斯核带宽：$h \in \{0.2, 0.35, 0.5, 0.8, 1.2\}$。
- LOF 邻居数：$k \in \{10, 20, 35, 50\}$（须小于最小训练样本数）。
- 1D 示意：$h \in \{0.2, 0.5, 1.2\}$ 三档。

## 5. 阈值与校准

- 每个检测器、每个参数**单独**用**正常验证集分数**的 99% 经验分位数设报警阈值（目标经验误报率约 1% 的操作点）。
- **补充操作点（合规敏感性分析）**：另报告 95% 经验分位数（≈5% FPR）下的指标，仅作操作点敏感性补充，**不改变主协议设计**；用于检验「结论是否依赖单一操作点」。
- 分数方向统一「越大越异常」：`s_KDE = -KernelDensity.score_samples`，`s_LOF = -LocalOutlierFactor(novelty=True).score_samples`。
- 阈值并列时按 `numpy.quantile` 的默认线性插值处理，记录该实现选择。
- 测试集**只在参数与流程锁定后**评估一次，测试标签不参与带宽、邻居数、阈值选择。

## 6. 指标定义

| 指标 | 说明 |
|---|---|
| ROC-AUC | 阈值无关排序指标 |
| Average Precision (AP) | `sklearn.average_precision_score`；注明测试异常比例（20%），因 AP 受类别比例影响 |
| Precision / Recall / F1 | 校准阈值操作点处报告 |
| 混淆矩阵 | TP/FP/FN/TN |
| 正常测试误报率 | FP/(FP+TN) |
| 分簇正常误报率 | 分别报告密集簇与稀疏簇的正常样本被误报比例，避免总体 FPR 掩盖问题 |

## 7. 核心实验矩阵

| 实验 | 固定项 | 改变项 | 主要输出 |
|---|---|---|---|

## 10. 修正记录（人机协作纠错证据）

1. **v1→v2（2026-11-27）**：初版 `anomaly_box=[[-6.5,-4.5],[4.5,6.5]]` 使异常点 x、y 都在 ±4.5~6.5，y 方向离正常簇 4.5~6.5 个标准差，导致所有模型 AUROC=AP=1.0、无区分度。修正：异常沿 x 轴分远端/边界两类，y 收窄到 [-1,1]。
2. **v2→v3（2026-11-27）**：边界异常初设 $x\in[3,4]$ 落在稀疏簇（均值 2、std=1）的 1–2 个标准差内，先验上与正常样本同分布，`recall_boundary≈0`。修正：边界异常改为 $x\in[4,5]$（稀疏簇尾部 2–3 个标准差，正常样本约 2.1%）。
3. 两次修正均基于数据生成先验（几何尺度），**非根据测试表现回调参数**；参数在看结果前已锁定。
4. **v3→v4（2026-11-27）**：按 B/C 反馈开启「空区紧凑簇(compact)」异常（原开关 enabled=false → true），三类异常各占 1/3。该异常置于两正常簇之间的空区 $(0,0)$、std=0.15，用于检验局部视角(LOF)与全局视角(KDE)的分歧。设计依据为 H3 理论（局部 vs 全局），**在加入该类型前已锁定，不依测试结果回调**。
   - 执行结果：1% FPR 下两类方法对 compact 的召回均≈0（阈值被远端异常与稀疏簇尾部占据）；但得分排序上 KDE 对 compact 的平均异常得分（约 3.9）明显高于 LOF（约 1.25），体现全局 vs 局部的分歧体现在排序而非阈值判定。
5. **结论（2026-11-27，C 交叉审查证伪）**：三类异常中**仅 distal 可用**（≡ 正式实现的 far）。
   - **boundary 证伪**：稀疏簇 sd=1.0，球壳取 2.5σ 时 $P(r\ge 2.5)=e^{-3.125}=4.39\%$，500 个正常点中约 22 个落在壳外且得分比被标为异常的壳内点更异常——**标签与得分自相矛盾，球壳式边界异常不可用**。
   - **compact@(0,0) 证伪**：实测 KDE 分 3.80 < 阈值 6.18、LOF 1.05 < 2.02，125 点检出率均 0%；该位置在两簇**鞍部**而非空区，不构成有效异常。
   - **最终口径**：论文主结果采用 C 的 **far + near@(0,5)**；A 侧 boundary/compact@(0,0) 降级为「**设计迭代记录**」（一次被证伪的设计 + 证伪依据，可作课程 15 分纠错素材）。
   - (0,0) 紧凑团可改造为 **P2「污染训练集」**材料（把紧凑团放进 train，测训练集不纯），但那是另一个研究问题，非局部异常检测。
