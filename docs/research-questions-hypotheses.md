## 2. 可证伪假设 H1–H4

### H1：带宽与密度估计平滑度

- **陈述**：在固定训练样本、同一核函数下，增大 KDE 带宽使估计更平滑；带宽过小时曲线保留更多局部波动，过大时可能抹平多峰结构。
- **可观测变量**：一维双峰样本上，小/中/大三档带宽对应的密度曲线形态（峰的个数、高度、宽度、局部起伏）。
- **测量指标**：峰的保留与合并（定性）；可选补充逐点估计的离散程度（定量）。
- **支持判据**：小带宽下双峰分立、局部极大数多；大带宽下显著峰数减少、谷填充率上升。（E0 实测：h=0.08/0.30/0.90 → 局部极大 8/3/2、显著峰 2/2/1、谷填充率 0.0007/0.1581/0.9140；显著峰按「prominence ≥ 全局最大密度 10%」口径）
- **推翻判据**：同一数据与核函数下，增大带宽**未**使显著峰数减少或谷填充率上升（显著峰 = prominence ≥ 全局最大密度的 10%，E0 口径）。
- **成立前提**：仅在固定 n、核函数、绘图区间下成立；这是**一维**双峰示例（E0：200 点、网格 x∈[−5,5] 共 1001 点）的原理示意，不作为普适收敛或偏差—方差阶的证明。

### H2：稀疏正常簇被全局阈值误报

- **陈述**：正常数据密度不均衡时，单一全局密度阈值可能把稀疏正常簇的部分尾部误报为异常。
- **可观测变量**：稀疏正常簇与密集正常簇样本的异常得分分布，及其在同一固定阈值下的判定结果。
- **测量指标**：分簇统计的正常样本误报率（稀疏簇 vs 密集簇），而非只看总体 FPR。
- **支持判据**：同一全局阈值下，稀疏簇误报率 **≥ 2× 密集簇误报率** 且 **≥ 2× 目标 1%**。（实测：核心运行 6 个 h 上稀疏簇 **2.0%–2.4%**、密集簇 **0.0%–0.4%**；10 种子均值稀疏簇 **2.16%–2.58%**——两者分别统计，不混用区间）
- **推翻判据**（与协议 §11 对齐）：在**全部 h** 上稀疏簇误报率**都不高于**密集簇，**或**两者差异落在多种子波动范围内。结果照实报告，不因不理想而回调。
- **成立前提**：阈值由正常验证集全局分位数校准（单一全局阈值）；若改用分簇阈值则本假设的「全局阈值」前提不成立。

### H3：LOF 与 KDE 在密度异质性下的差异

- **陈述**：局部密度比较可能缓解部分由密度异质性带来的误报，但 LOF 对邻居数与局部结构敏感，不预设它整体优于 KDE。
- **可观测变量**：在相同数据划分、相同正常验证集校准到同一目标经验误报率后，KDE 与 LOF 的测试得分与判定。
- **测量指标**：ROC-AUC、AP、校准阈值下的 recall 与 F1、分类型召回、稀疏正常簇误报率。
- **支持判据**：LOF 在稀疏正常簇误报率上不高于（甚至低于）KDE，或对某类局部异常召回更高。
- **推翻判据**：LOF 在稀疏正常簇误报率上**不低于** KDE，**且**在其余指标（AUC/AP/召回）上也**无优势**（合取；「LOF 整体指标略逊」本就在 H3「不预设整体更优」的预期内，不算推翻）。结果照实报告，不因不理想而回调。
- **成立前提**：LOF 使用支持新样本评分的 novelty 模式、仅在训练正常样本上拟合；邻居数经与 KDE 同等的选择规程确定。

### H4：似然最优带宽 ≠ 检测最优带宽

- **陈述**：按正常验证集（对数）似然选出的带宽，与按异常检测验证指标选出的带宽可能不同，因为两个目标函数不同。
- **可观测变量**：①按**正常验证集（对数）似然**选出的带宽 h_lik（协议下唯一合法的选择准则）；②在**测试集**上事后描述性对比各带宽的检测指标，取 argmax 记为 h_det^test（**仅作事后描述，不是选择准则**——验证集只含 1000 个正常样本、0 个异常，算不出 AUC/AP/召回）。
- **测量指标**：h_lik 与 h_det^test 是否一致；h_lik 对应的测试检测指标是否已接近测试 argmax。
- **支持判据**：两个带宽不同，且 h_lik 对应的检测指标并非测试 argmax。
- **推翻判据**：两带宽一致，或 h_lik 已同时达到测试 argmax。
- **成立前提**：h_det^test 只用于**事后描述**，不得反过来用于选带宽（否则构成测试集泄漏）。协议规定 validation 只含正常样本，因此**不存在「用验证集检测指标选 h」的合法路径**；若需真正的检测准则，须新增带标签 dev 集（超出当前协议范围，不采用）。

## 3. 阶段 0 先行约定的符号与方向

> 在 B 的实验协议与 C 的实现落地前，先把以下符号与方向锁定，确保全文一致（对应任务书「概念与公式准确、区分概率与概率密度、符号规范」）。

- **KDE 估计式**（核函数缩放与带宽约定按此全文统一）：

$$
\widehat p_h(x)=\frac{1}{n h^d}\sum_{i=1}^{n}K\!\left(\frac{x-x_i}{h}\right),
$$

其中 n 为训练样本数、d 为维数、h 为带宽、K 为核函数。

- **异常得分**（统一「越大越异常」）：

$$
s_{KDE}(x)=-\log \widehat p_h(x).
$$

- **阈值方向**：得分越大越异常；阈值由正常验证集分数的 99% 经验分位数确定（目标经验误报率约 1% 的操作点），另报告不依赖阈值的排序指标。
- **概率 vs 密度**：KDE 估计的是概率密度。连续分布单点概率为 0，区间概率需对密度积分；密度数值不要求落在 [0,1]。
- **LOF 语义**：LOF 比较样本与邻域的局部可达密度，反映局部相对稀疏程度，**不输出 KDE 意义下的概率密度**。不同库可能以负分编码异常程度，正式实现须实测与文档确认符号方向，不能只按函数名推断。
