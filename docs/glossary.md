# 术语表（A · 理论负责人）

> 口径统一版，供全组、实验协议与论文引用。与 `docs/theory-note.md`、`docs/research-questions-hypotheses.md` 保持一致。
> 状态：草稿，待全组核准后冻结。

| 术语 | 定义 / 本项目约定 |
|---|---|
| 核密度估计 KDE | 用核函数对每个样本贡献求和得到的非参数概率密度估计：$\widehat p_h(x)=\frac{1}{n h^d}\sum_i K((x-x_i)/h)$ |
| 带宽 $h$ | 控制每个样本影响范围的平滑参数；本项目取各向同性标量，每个维度同一个 $h$ |
| 核函数 $K$ | 满足归一化 $\int K(u)\,\mathrm du=1$ 的函数；本项目**仅使用高斯核**（`KernelDensity(kernel="gaussian")`），**未做均匀核对照**，论文不得声称做过 |
| 各向同性带宽 | 所有维度共享同一标量带宽；更一般的带宽矩阵本项目不采用 |
| 概率密度 $p(x)$ | 非负、全空间积分为 1 的函数；数值可大于 1 |
| 概率 | 密度在区域上的积分；连续分布单点概率为 0 |
| 异常分数 $s$ | $s_{KDE}(x)=-\log\widehat p_h(x)$；**越大越异常**，全文一致 |
| 阈值 | 正常验证集异常分数的 99% 经验分位数；$s(x)>$ 阈值判异常。实现锁定为 `numpy.quantile(scores_val, 0.99, method="inverted_cdf")`（实现方法见协议 §5） |
| 局部异常因子 LOF | 比较点 $x$ 局部可达密度与其邻域点局部可达密度的比值；输出相对稀疏度，非概率密度 |
| 局部可达密度 | LOF 中由 $k$-距离邻域定义的点密度，用于局部比较 |
| novelty 模式 | LOF 对**新样本**评分的模式；仅用训练正常样本拟合 |
| 训练集 / 验证集 / 测试集 | 训练=仅正常样本拟合模型；验证=正常样本校准阈值；测试=含异常样本，仅在流程锁定后做最终评估 |
| 目标经验误报率 | 由验证集 99% 分位数设定的约 1% 操作点；只表示验证集经验水平，不承诺测试分布严格达到 1% |
| 密度异质性 | 正常数据中不同簇密度不同的情形，是 H2/H3 的关键设定 |
| ROC-AUC | 阈值无关的排序指标，衡量异常分数区分正常/异常的能力 |
| Average Precision (AP) | **阶梯式** AP（按 sklearn `average_precision_score` 定义：沿 PR 曲线以阶梯方式求和，**不是**梯形积分下的 PR-AUC）；受测试集异常比例影响，须同时报告 prevalence |
| Precision / Recall / F1 | 固定阈值下的精确率、召回率与调和平均，随阈值操作点报告 |
| 稀疏正常簇误报率 | 分簇统计的正常样本误报率，避免总体 FPR 掩盖密度异质问题 |
| 随机种子 | 固定并分别登记的数据生成/划分随机源，保证可复现；本项目两个检测器（`KernelDensity`、`LocalOutlierFactor`）均为确定性算法、不消耗随机数，**无模型初始化种子** |
| 混淆矩阵 | 固定阈值下 TP/FP/FN/TN 计数，随校准阈值报告 |
| 显著峰 / prominence | E0 一维示意中，局部极大且 prominence ≥ 全局最大密度的 **10%** 的峰；用于量化「双峰是否被抹平」 |
| 谷填充率 | 两峰之间谷底密度与全局最大密度之比；越大说明双峰结构越被填平（E0 实测：h=0.08/0.30/0.90 → 0.0007/0.1581/0.9140） |
| 等价错排配对数 | $(1-\mathrm{AUC})\cdot n_{\text{异常}}\cdot n_{\text{正常}}$，把饱和的 AUC 差距换算成「被错排的配对数」（E1 实测：h=0.10 为 256 对、h=1.20 为 34 对） |
| $h_{lik}$ / $h_{det}^{test}$ | $h_{lik}$：按**正常验证集对数似然**选出的带宽（唯一合法选择准则）；$h_{det}^{test}$：**测试集上事后描述性 argmax**，仅描述、**不是选择准则**（验证集 0 异常，算不出 AUC/AP/召回） |

## 符号对照（冻结）

| 符号 | 含义 |
|---|---|
| $n$ | 训练样本数 |
| $d$ | 维数 |
| $h$ | 带宽 |
| $K(\cdot)$ | 核函数 |
| $x_i$ | 第 $i$ 个训练样本 |
| $x$ | 待评分的点 |
| $\widehat p_h(x)$ | 带宽 $h$ 下的密度估计 |
| $s(x)$ | 异常分数 |
| $k$ | LOF 邻居数 |
